# JavaScript Learning

This repository contains beginner-friendly JavaScript examples and notes.

## Included files

- `01_Chapter_JS_Basics.js` — basic JavaScript output example
- `02_math.js` — a simple arithmetic example
- `JS_Identifiers_keywords.md` — notes on JavaScript identifiers and keywords

## Run the examples

```bash
node 01_Chapter_JS_Basics.js
node 02_math.js
```

Or use the npm scripts:

```bash
npm run start
npm run math
```

## Notes

This is intended as a learning workspace for JavaScript fundamentals.
